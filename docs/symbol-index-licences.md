# Symbol index and draw prototypes – data sources and licences

`src/assets/symbol-index.json` (the searchable symbol index) is generated by
`npm run symbols:generate` (`scripts/generate-symbol-index.mjs`) from two
external datasets, filtered to what the bundled MathLive version can render.
`src/assets/draw-prototypes.json` (draw-to-find's stroke prototypes) is
generated by `npm run draw:prototypes` (`scripts/generate-draw-prototypes.mjs`)
from the Detexify training data. Generation is a manual, development-time
step – the build itself stays fully offline. The generated files are
committed. The symbol generator fetches each dataset from the commit pinned
in its `SOURCES` table and refuses any download whose SHA-256 differs from
the pinned hash, so the committed index is reproducible from the revisions
recorded below (and in the index's own `upstream` field).

The runtime libraries the extension bundles (MathLive, the KaTeX fonts, STIX
Two Math, Speech Rule Engine, MiniSearch) are covered by
`dist/THIRD-PARTY-NOTICES.txt`, written on every build – see the Licence
section of the README.

## Structural templates

The structural entries (fractions, roots, integrals, matrices, …) are our own
template list, seeded by consulting the publicly documented KaTeX
supported-functions catalogue (MIT) for coverage, with descriptions written
for this project.

## Expression-library starter pack

The optional starter formulae (`src/sidepanel/library-starter.ts` – the
quadratic formula, standard deviation, Maxwell's equations and so on) were
written for this project as LaTeX from the mathematics itself, not copied
from any other project's snippet collection. Short mathematical expressions
of this kind attract no meaningful copyright; writing them ourselves removes
the question entirely.

## MiniSearch (runtime dependency)

The search itself runs on [MiniSearch](https://github.com/lucaong/minisearch)
(MIT License), bundled like every other dependency – no network is involved
at runtime.

## Detexify training data (draw-to-find prototypes)

- **Author**: Daniel Kirsch and the Detexify contributors (crowdsourced)
- **Source**: <https://github.com/kirel/detexify-data>
- **Licence**: [Open Database License (ODbL) 1.0](https://opendatacommons.org/licenses/odbl/1-0/)
- **What we take**: for each symbol the app can insert, a handful of
  representative human drawings (stroke point sequences), selected by
  clustering and quantised, as `src/assets/draw-prototypes.json`; and a
  held-out benchmark slice of the same data (up to 12 drawings per class,
  original coordinates) as `scripts/data/detexify-heldout.json.gz`, used
  only by the development benchmark (`npm run draw:benchmark`) and never
  bundled into the extension.

ODbL compliance: `draw-prototypes.json` and the benchmark fixture are
derivative databases of the Detexify sample data and are themselves made
available under the ODbL 1.0 – each file's `sources` field carries the
notice, and this document the attribution. The
extension that bundles it remains MIT-licensed; the ODbL's share-alike
obligation attaches to the derived data, which is published in this
repository. The original database is not shipped with the extension, and
modifications (class mapping, filtering, clustering, quantisation) are
described in `scripts/generate-draw-prototypes.mjs`.
